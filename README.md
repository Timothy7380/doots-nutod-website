# DOOTS Nutod Nigeria Limited — Website Prototype

Responsive e-commerce and marketplace website prototype for **DOOTS Nutod Nigeria Limited**, an agro-commodities company in Ibadan, Nigeria (cocoa, soya beans, sesame, cashew).

**Live site:** https://timothy7380.github.io/doots-nutod-website/

## Features (prototype)
- Product listings with category filters, search and product detail views
- Cart and 3-step checkout: delivery, payment method (card, bank transfer, USSD, escrow), confirmation
- Customer accounts (buyer / seller) with order history
- Seller marketplace: verified sellers and a "list new produce" form
- "DOOTS Pay" payments overview, company info, gallery and contact form
- Fully responsive from 320px phones up to large desktop screens

## Notes
- Prices, sample sellers and payments are placeholders. No real charges are made, and data is kept in memory only.
- For production, connect a payment gateway (e.g. Paystack or Flutterwave) and a backend for accounts, orders and listings.
